# AGENTS.md

## Project Overview

This repository runs hate-speech classification over meme images. Images live in
`images/`, per-image model outputs are written to `results/*.jsonl`, and merged
tabular output is written to `results/results.csv`.

## Environment

- Use `python3`; `python` may not be available on macOS.
- The batch jobs require `OPENROUTER_API_KEY` in the environment.
- Do not commit or print real API keys. If a key is exposed in chat or logs,
  recommend rotating it.

## Main Workflow

Generate the batch runner:

```bash
python3 generate_batch_run.py
```

Optional: change concurrency when generating the runner:

```bash
python3 generate_batch_run.py --max-jobs 8
```

Run the generated batch:

```bash
export OPENROUTER_API_KEY=sk-or-...
bash batch_run.sh
```

Merge per-image JSONL outputs into CSV:

```bash
python3 merge_results_to_csv.py
```

Expected merged output:

```text
results/results.csv
```

## Generated Files

- `batch_run.sh` is generated by `generate_batch_run.py`.
- `results/*.jsonl` are generated by `single-image-process.py`.
- `results/results.csv` is generated by `merge_results_to_csv.py`.

When rerunning batches, note that per-image JSONL files may be overwritten.

## Troubleshooting

- If every job prints `Please set OPENROUTER_API_KEY first`, set the environment
  variable and rerun `bash batch_run.sh`.
- If jobs fail with `Connection error`, outbound network access may be blocked.
  Rerun with network permission if the environment requires approval.
- If `python` is not found, use `python3`.
